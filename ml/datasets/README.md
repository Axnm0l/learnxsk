# Cybersecurity & Systems Datasets Collection

This directory contains the 8 datasets requested, downloaded and organized into separate subdirectories:

---

## 1. Linux Terminal Commands Dataset
- **Folder:** [`Linux_Terminal_Commands_Dataset`](./Linux_Terminal_Commands_Dataset)
- **Source:** [darkknight25/Linux_Terminal_Commands_Dataset](https://huggingface.co/datasets/darkknight25/Linux_Terminal_Commands_Dataset)
- **Key Files:**
  - `LINUX_TERMINAL_COMMANDS.jsonl`: Terminal command prompts, commands, and explanation pairs.
  - `README.md`: Dataset documentation.

---

## 2. CyberMetric
- **Folder:** [`CyberMetric`](./CyberMetric)
- **Source:** [tihanyin/CyberMetric](https://huggingface.co/datasets/tihanyin/CyberMetric)
- **Key Files:**
  - `CyberMetric-10000-v1.json`: 10,000 cybersecurity evaluation questions.
  - `CyberMetric-2000-v1.json`: 2,000 question benchmark subset.
  - `CyberMetric-500-v1.json`: 500 question benchmark subset.
  - `CyberMetric-80-v1.json`: 80 question benchmark subset.
  - `README.md`: Benchmark overview and schema.

---

## 3. Kali Linux Toolkit Dataset
- **Folder:** [`KALI_LINUX_TOOLKIT_DATASET`](./KALI_LINUX_TOOLKIT_DATASET)
- **Source:** [barisKacin/KALI_LINUX_TOOLKIT_DATASET](https://huggingface.co/datasets/barisKacin/KALI_LINUX_TOOLKIT_DATASET)
- **Key Files:**
  - `KALI_LINUX_TOOLS_DATASET.jsonl`: Kali Linux penetration testing and security toolkit commands and descriptions.
  - `README.md`: Dataset documentation.

---

## 4. SecBench
- **Folder:** [`SecBench`](./SecBench)
- **Source:** [secbench-hf/SecBench](https://huggingface.co/datasets/secbench-hf/SecBench)
- **Key Files:**
  - `data/MCQs_2730.jsonl`: 2,730 multiple-choice cybersecurity evaluation questions.
  - `data/SAQs_270.jsonl`: 270 short-answer questions.
  - `figs/`: Architectural and benchmarking figures.
  - `README.md`, `README_CN.md`: Detailed benchmark instructions.

---

## 5. CyberSec-Bench
- **Folder:** [`CyberSec-Bench`](./CyberSec-Bench)
- **Source:** [AYI-NEDJIMI/CyberSec-Bench](https://huggingface.co/datasets/AYI-NEDJIMI/CyberSec-Bench)
- **Key Files:**
  - `cybersec_bench.jsonl`: Cybersecurity benchmark questions and evaluations.
  - `README.md`: Dataset details.

---

## 6. Trendyol Cybersecurity Instruction Tuning Dataset
- **Folder:** [`Trendyol-Cybersecurity-Instruction-Tuning-Dataset`](./Trendyol-Cybersecurity-Instruction-Tuning-Dataset)
- **Source:** [Trendyol/Trendyol-Cybersecurity-Instruction-Tuning-Dataset](https://huggingface.co/datasets/Trendyol/Trendyol-Cybersecurity-Instruction-Tuning-Dataset)
- **Key Files:**
  - `CyberSec-Dataset_escaped.jsonl`: Comprehensive instruction-tuning dataset for cybersecurity LLMs (186 MB).
  - `README.md`: Dataset documentation.

---

## 7. CTI-Bench (Cyber Threat Intelligence Bench)
- **Folder:** [`cti-bench`](./cti-bench)
- **Source:** [AI4Sec/cti-bench](https://huggingface.co/datasets/AI4Sec/cti-bench)
- **Key Files:**
  - `cti-mcq.tsv`: Multiple choice question dataset.
  - `cti-ate.tsv`: Attack Technique Extraction task.
  - `cti-taa.tsv`: Threat Actor Attribution task.
  - `cti-vsp.tsv`: Vulnerability Severity Prediction task.
  - `cti-rcm.tsv`, `cti-rcm-2021.tsv`: Report Category Matching tasks.
  - `README.md`: Task descriptions and evaluation protocol.

---

## 8. NIST NICE Framework
- **Folder:** [`NIST-NICE-Framework`](./NIST-NICE-Framework)
- **Source:** [NIST NICE Framework Resource Center](https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center/nice-framework-current-versions)
- **Key Files:**
  - `NICE Framework Components v2.2.0.xlsx`: Official components spreadsheet (Work Roles, Tasks, Knowledge, Skill statements).
  - `v2-2-0_nf_components.json`: Official complete JSON format components database.
  - `NIST.SP.800-181r1.pdf`: Official Workforce Framework for Cybersecurity specification PDF.
  - `NICE Framework to CSF Mapping - v2.0.0 to v2 - September 2025.xlsx`: Mapping to NIST Cybersecurity Framework 2.0.
  - `C3 Credentials Mapping to NICE Work Roles - v2.0.0 - March 2025.xlsx`: Mapping of certifications and credentials to work roles.
  - `README.md`: Source URLs and metadata.
